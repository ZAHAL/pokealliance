# Pokelog ATK 5 — PokeAlliance

Plano para chegar a 1.600 pts de pokelog (ATK 5, +10% de ATK), do pokelog mais barato ao mais caro, em seis fases: Arcane Shards, instâncias, 1.5k rápidos, 1.5k restantes e combos, 3k, e 4k até fechar a meta.

Baseado no guia de pokelogs de Hegress (Guild Arkham, servidor Sun). São 157 pokelogs (o guia lista 162, mas cinco nomes se repetem). Com shiny em todos, 134 bastam.

## Uso

Abra `index.html` no navegador. Marque cada pokelog fechado (✓) e cada shiny (★). O placar mostra quantos pontos faltam e qual é o próximo.

O progresso desta cópia fica salvo só neste navegador. A [página publicada](https://claude.ai/code/artifact/dd017413-268a-47e8-8168-4c50f3bcc87f) salva na sua conta do Claude. As duas não se sincronizam.
